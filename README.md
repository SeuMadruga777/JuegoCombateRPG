# 🗡️ JuegoCombateRPG

**Proyecto académico de simulación de combate RPG por turnos en consola.**  
Permite enfrentar distintos tipos de personajes con habilidades únicas y resultados dinámicos.

---

## 📌 Descripción

Este programa permite simular una batalla por turnos entre personajes como Bárbaros, Sacerdotes, y un personaje personalizado (Campesino). Cada personaje tiene atributos como vida, ataque y equipo, y puede tener comportamientos especiales durante el combate.

Incluye:
- Equipamiento que modifica ataque y defensa
- Transformaciones con probabilidades (como Hombre Lobo)
- Personajes únicos con habilidades distintas
- Resultado final con detección de empate

## 🎯 Objetivo

Este proyecto fue desarrollado como parte de una entrega académica, cumpliendo con una rúbrica que exige:

- Uso de clases con herencia y métodos sobrescritos
- Simulación de batallas por rondas
- Equipamiento con objetos que modifican atributos
- Creación de un personaje adicional con comportamiento especial
- Uso de Git y GitHub para control de versiones y entrega

---

## 🚀 Cómo ejecutar

1. Abre la solución `JuegoCombateRPG.sln` en Visual Studio.
2. Compila el proyecto.
3. Ejecuta el programa desde consola (`Start`) y sigue las instrucciones interactivas.
4. Observa el resultado de la batalla entre personajes.
